# Path Filter & BND Editor

ปลั๊กอิน QGIS สำหรับงานรังวัดที่ดิน ใช้กรองข้อมูลแปลงที่ดินด้วย `PATH` / `FILE_NAME`
แก้ไข Attribute UTM พร้อมคำนวณ `PATH` ใหม่ให้อัตโนมัติ และแก้ชื่อหมุดหลักเขต (`BND_NAME`)
โดยคลิกเลือกแปลงหรือหมุดบนแผนที่โดยตรง

**ผู้พัฒนา:** นายภาคภูมิ สูบกำปัง — วิศวกรรังวัดปฏิบัติการ กองเทคโนโลยีทำแผนที่ กรมที่ดิน

## ความสามารถ

| ปุ่ม | หน้าที่ |
|---|---|
| เริ่ม Filter (ซูมอัตโนมัติ) | กรอง Layer หมุดและแปลงด้วย `PATH` และ/หรือ `FILE_NAME` แล้วซูมไปยังผลลัพธ์ ถ้าเจอมากกว่า 1 แปลงจะเปิดหน้าต่างรายการให้ไล่ตรวจ |
| แสดงทั้งหมด (Clear) | ล้าง filter ของทั้งสอง Layer แล้วปิดหน้าต่างผลการค้นหา |
| แก้ไข Attribute (คลิกเลือกแปลงบนแผนที่) | คลิกแปลงเพื่อแก้ `UTMMAP1-4`, `UTMSCALE`, `LANDNO` แล้วสร้างค่า `PATH` ใหม่ให้ทั้งแปลงและหมุดของแปลงนั้น |
| แก้ไขชื่อหมุดหลักเขต | คลิกหมุดบนแผนที่เพื่อแก้ `BND_NAME` |
| อัปเดตปลั๊กอิน | เทียบเวอร์ชันกับ GitHub แล้วดาวน์โหลดทับให้ (เช็คให้เองทุกครั้งที่เปิดปลั๊กอินด้วย) |

### หน้าต่างผลการค้นหา
- **คลิกรายการ** = ซูมไปที่แปลงนั้น
- **ติ๊กถูก** = ทำเครื่องหมายว่าเป็นแปลงที่ตรวจสอบแล้ว/ถูกต้อง (เขียนค่าลงคอลัมน์ `OWNERNAME` แล้วบันทึกลงไฟล์ทันที) รายการที่ติ๊กแล้วจะแสดงเป็น **ตัวหนา** เพื่อให้เห็นชัดว่าตรวจถึงไหนแล้ว
- เปิดหน้าต่างใหม่อีกครั้ง รายการที่เคยติ๊กไว้จะยังติ๊กและเป็นตัวหนาอยู่ (อ่านค่าจากไฟล์)

### การคลิกบนแผนที่
- **คลิกซ้าย** = แก้ไขทีละ 1 แปลง
- **Shift + คลิกซ้าย** = เลือกสะสมหลายแปลง
- **คลิกขวา** = เปิดหน้าต่างแก้ไขของแปลงที่เลือกไว้ / ยกเลิกการเลือก

## การติดตั้ง

คัดลอกโฟลเดอร์นี้ทั้งโฟลเดอร์ไปไว้ใน profile ของ QGIS แล้วเปิด QGIS ใหม่:

```
%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\Filter_PATH
```

เปิดใช้งานที่ **Plugins → Manage and Install Plugins → Installed** แล้วติ๊ก *Path Filter & BND Editor*
เมนูจะอยู่ที่ **Vector → Land Dept Tools** และมีไอคอนบน Toolbar

ต้องการ QGIS 3.0 ขึ้นไป

## การอัปเดต

ทุกครั้งที่เปิดปลั๊กอิน ปลั๊กอินจะเทียบเลขเวอร์ชันกับ `metadata.txt` บน GitHub เอง ถ้ามีเวอร์ชันใหม่กว่า
จะเด้งหน้าต่างแจ้งเตือนพร้อมปุ่ม **อัปเดตเลย** (หรือกดปุ่ม **อัปเดตปลั๊กอิน** ในหน้าต่างเครื่องมือเมื่อไรก็ได้)

กดอัปเดตแล้วปลั๊กอินจะดาวน์โหลดจาก branch `main` มาเขียนทับ ปิดหน้าต่างเดิม แล้วโหลดเวอร์ชันใหม่ให้ทันที
เปิดปลั๊กอินอีกครั้งก็ได้เวอร์ชันใหม่เลย **ไม่ต้องปิด-เปิด QGIS** (ยกเว้นการอัปเดตจาก 4.0.0 หรือเก่ากว่า
ซึ่งยังต้องปิด-เปิด QGIS ใหม่หนึ่งครั้ง)

## คอลัมน์ที่ชั้นข้อมูลต้องมี

คอลัมน์ที่ขาดไปปลั๊กอินจะข้ามให้เอง ไม่ทำให้โปรแกรมพัง แต่ความสามารถส่วนนั้นจะใช้ไม่ได้

| คอลัมน์ | อยู่ที่ Layer | ใช้ทำอะไร |
|---|---|---|
| `PARCELDESC` | ทั้งสอง | รหัสแปลง ใช้จับคู่ว่าหมุดจุดไหนเป็นของแปลงใด — **จำเป็นต้องมี** ไม่งั้นจะแก้ได้เฉพาะแปลง |
| `PATH`, `FILE_NAME` | ทั้งสอง | เงื่อนไขการกรอง และ `PATH` ถูกคำนวณใหม่ตอนบันทึก |
| `UTMMAP1-4`, `UTMSCALE` | ทั้งสอง | ค่าที่กรอกในหน้าต่างแก้ไข Attribute |
| `LANDNO` (สำรอง `LAND_NO`) | ทั้งสอง | ต่อท้ายค่า `PATH` ที่คำนวณใหม่ |
| `OWNERNAME` | แปลง | เก็บเครื่องหมายแปลงที่ติ๊กว่าตรวจแล้ว |
| `BND_NAME`, `BND_ORDNO` | หมุด | ชื่อและลำดับหมุดหลักเขต |
| `PARCELNO`, `SURVEYNO`, `RAI`, `NGAN`, `WA` | แปลง | แสดงในรายการผลการค้นหาเพื่อยืนยันว่าเลือกถูกแปลง

หมุดจะถูกแก้ไขตามแปลงก็ต่อเมื่อ `PARCELDESC` ตรงกัน และอยู่ในบริเวณเดียวกับแปลงที่คลิกเลือก
หมุดที่รหัสตรงแต่ตำแหน่งห่างออกไปเกิน 10 เมตร ปลั๊กอินจะถามก่อนว่าจะรวมเข้ามาแก้ด้วยหรือไม่
